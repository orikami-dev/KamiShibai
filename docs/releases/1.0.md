# 1.0

Première version publique de Kamishibai : SmartTube avec une interface de téléphone.

- Un seul écran : la vidéo monte dans un panneau par-dessus l'Accueil, et le bouton PiP la réduit en mini-lecteur.
- Shorts à la verticale, avec les actions sur le côté, comme sur YouTube.
- Recherche intégrée à la barre du haut ; barre du bas Accueil, Shorts, Abonnements, Historique, Paramètres.
- Six palettes (Washi, Sumi, Ai, Matcha, Sakura, Kin), avec le logo et l'icône de l'app assortis.
- Sur un pliant à moitié ouvert, en plein écran : la vidéo au-dessus de la charnière, les commandes en dessous.
- Menus du lecteur qui s'ouvrent depuis leur bouton, réglages en tuiles, démarrage sans écran de logo.
- Mises à jour intégrées : les prochaines versions te seront proposées dans l'app.

**Installation** : télécharge `Kamishibai-1.0.apk` ci-dessous et ouvre-le sur ton téléphone. Il s'installe à côté de SmartTube. Si tu avais une version de test de Kamishibai, désinstalle-la d'abord : la 1.0 est signée avec une nouvelle clé.

Basé sur SmartTube 32.68 de yuliskov (MIT).
